# Security

Please report a security problem privately, not in a public issue: email support@smstunnel.io with "Security: smstunnel-mcp" in the subject. Say what you found, how to reproduce it, and which version you ran (`npx -y @narcisbodea/smstunnel-mcp --version`). We'll reply and tell you when it is fixed.

Fixes go into the latest release on npm, `@narcisbodea/smstunnel-mcp`; please check that one first.

Never put a real API key in a report. If a key may have leaked, delete its app in the SMSTunnel dashboard (https://dashboard.smstunnel.io/apps) to cut it off, then create a new one.
